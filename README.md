# Tratamiento Digital de Imágenes en JavaScript

### Keywords

JavaScript · Imágenes · Algoritmos · Transformación

### Resumen

Una imagen es, en esencia, un mapa de bits, y aunque pueda parecer una estructura de datos demasiado simple como para sacarle provecho, la realidad es muy distinta. Las posibilidades de análisis y transformación en el procesamiento digital de imágenes son enormes.

A lo largo de esta charla haremos un recorrido práctico por estas técnicas creando, mediante live coding, un framework de tratamiento de imágenes en JavaScript. Analizaremos desde la manipulación básica de píxeles para generar efectos visuales hasta la aplicación de filtros de convolución, algoritmos de detección de bordes y visión artificial, sin olvidar el ajuste de color mediante el histograma de frecuencias.
